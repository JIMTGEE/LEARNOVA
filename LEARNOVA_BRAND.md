# Learnova brand system

## Product identity

- Product: **Learnova**
- Tagline: **A new beginning for learning.**
- Meaning: Learn + Nova (a new star / a new beginning)
- Primary: deep navy `#0B2233`
- Teal: `#087F8C`
- Cyan: `#35C6D5`
- Mint: `#C8F2E7`
- Mark: `assets/images/learnova-mark.svg` (open book and rising star)

## Shared UI layer

Load `assets/css/learnova-premium.css` and `assets/js/learnova-branding.js` in shared layouts. The current branding script loads the theme stylesheet automatically and performs a conservative visible-text update for old product mentions. It deliberately does not rewrite routes, identifiers, tenant/school names, backend values, scripts, or stored data.

## Asset usage

Do not remove school logos, user-uploaded photos, submissions, assessments, chat attachments, learning resources, signed/sealed documents, vendor-library assets, or database backups as part of a generic branding cleanup. Review each asset's references and data-retention requirements first. See `LEARNOVA_MEDIA_AUDIT.md`.
